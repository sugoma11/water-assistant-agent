# Generate Response Schema

Regenerates Pydantic models from the predefined JSON Schema file.

## When to use

Run this skill after editing
`src/contract_parsing/extractors/rate_plan_extractor/response_schema/extraction_response_schema.json`.

## Steps

1. Run the codegen command:

```bash
just generate-response-schema
```

2. Verify the generated file has no lint issues:

```bash
just ruff src/contract_parsing/extractors/rate_plan_extractor/response_schema/generated.py
```

3. Ensure the `from __future__ import annotations` line in `generated.py` includes
   the inline comment `# auto-generated by datamodel-codegen (forward refs)`. If the
   comment was stripped by codegen, re-add it.

4. Run tests to verify schema consistency:

```bash
just test tests/unit/test_response_schema.py tests/unit/test_schema_sync.py
```
